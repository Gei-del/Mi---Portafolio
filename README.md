# Portafolio profesional — Lorena Pontón

Portafolio web de **Geidy Lorena Ponton Campo**, orientado a procesos de selección para perfiles de **Desarrollo de Software / Full Stack**, con énfasis en **Java & Spring Boot, React/Next.js, APIs REST, SQL, datos e IA aplicada**.

## Objetivo

Presentar de forma clara y profesional:

- Perfil técnico y propuesta de valor.
- Experiencia reciente como desarrolladora Full Stack.
- Proyectos seleccionados por evidencia técnica, no por cantidad.
- Stack organizado por capacidades: backend, frontend, datos y herramientas.
- Formación, hackathons y logros relevantes.
- Acceso directo a GitHub, LinkedIn, CV y contacto.

## Experiencia de usuario

El portafolio incluye dos formas de exploración:

- **Vista normal:** una experiencia visual e interactiva con filtros de proyectos, animaciones sutiles y navegación por secciones.
- **Modo reclutador:** reduce elementos decorativos y prioriza experiencia, stack, proyectos, formación y contacto.

También incorpora:

- Diseño responsive para móvil, tablet y escritorio.
- Navegación accesible y soporte para `prefers-reduced-motion`.
- Filtros de proyectos por categoría.
- Copia rápida del correo profesional.
- Estado activo de navegación según la sección visible.

## Proyectos destacados

- **Kwesx IA** — Inteligencia territorial, datos abiertos, ETL, FastAPI, PostgreSQL y ML.
- **Auditor IA** — Auditoría e inventario operacional, trabajo offline e IA aplicada.
- **KAIROS Live** — Experiencia multijugador en tiempo real con Next.js, TypeScript y Supabase.
